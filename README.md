# The Barber Studio — Premium Barbershop Template

Plantilla de barbería con paleta negro, crema y dorado.

## Personalización

- Cambia la marca, el equipo, los testimonios, los servicios, los precios y los horarios en `index.html`.
- Alex Morgan, Liam Carter y Noah Bennett son nombres ficticios de muestra. Las identidades de ejemplo no identifican a las personas fotografiadas.
- La dirección `123 Main Street, Suite 1`, la ciudad y el código postal son marcadores de ejemplo.
- El enlace de indicaciones abre Google Maps sin señalar ningún negocio. Sustitúyelo por la ubicación del cliente.
- Los iconos sociales enlazan a las páginas principales de cada plataforma.
- Las respuestas del FAQ y la página de reservas están pendientes de personalización.
- `css/main.css` importa los estilos. Cada sección se edita en `css/sections/`.
- La foto `images/shop/barbershop-visit.webp` es una imagen generada de un local ficticio, sin marcas, optimizada a 900 × 1200 px.

Los textos y testimonios son contenido de demostración para la plantilla.
